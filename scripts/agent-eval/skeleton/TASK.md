# Task: shop modules

Implement the four modules of this application with DI Bag (`di-bag`,
installed): `catalog`, `inventory`, `checkout`, and `notifications`. Each
module's `TASK.md` in `src/features/<name>/` describes its contract and
behavior; apply those descriptions, except that you work on all four modules
and may change files in every `src/features/<name>/` directory.

`src/app.ts` and every `contract.ts` are fixed. When you are done,
`npm run typecheck` and `npm test` pass.
