# Findings from reading the code (controller, 2026-09-21), to be confirmed by prototype before the plan fixes any signature

- Runtime: contributions live in `BindingGraph.#contributions`, a map keyed by symbol that is separate from `#publicSlots`. `BagRuntime.resolve(key)` goes through `publicBinding(key)` and never sees contributions; `resolveAll` calls `ScopeAcquisitions.resolveCollection`. So `resolve` of a collection symbol needs a branch: when a public slot exists for that symbol it is a replacement and wins; otherwise return `resolveCollection(symbol)`. The same branch is needed in `acquire` (for `ensureServicesReady`), in `inspect`, and in the dependency proxy's `read` path, which today reaches collections only through the `all` flag.
- Types, admission: `TokenMember<R, T>` in `src/token-types.ts` admits a token only when `TokenKey<T> extends keyof R`. Contributions are not in the registrations map `R`; they are `Contribution<T, V>` members of the builder's constraint parameter. A collection token therefore always fails through `MissingToken`. `resolve`, `inspect` and the key tuple of `ensureServicesReady` need a second admission path for collection tokens that uses `CollectionMember<T, C>` from `src/contribution-types.ts`, and `resolve` needs a return type conditional on the token kind. This is the cost that spike S5 measures.
- Types, dependency tuples: `ReferenceGraph<T>` puts `all(...)` references into a separate `all` member through `DependencyKind<H>`, and `MissingTokens<R>` demands a singular binding for every REQUIRED token. When the `'all'` reference kind is removed, a bare collection token in a tuple must be routed into that `all` member by its token kind (so `DependencyKind` of a `CollectionToken` is the collection kind, not `'required'`), and `DependencyValue` must yield `readonly Item[]` for it. Otherwise graph completeness will reject every consumer of a collection as missing a service. `lazy(collectionToken)` needs the same routing.
- A replacement of a collection in `fork`/`createScope`/`replace` lands in the registrations map under the collection's symbol. Decide and prototype how `Selection`/`TokenMember` admit a collection token as a REPLACED key when that symbol is not yet in `R`.
