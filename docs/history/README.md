# Historical experiments

These files preserve the pre-v0.1 experiments, including v13 and the v14 proof
of concept. They are excluded from the active build and published package.
Some require obsolete dependencies or contain intentional type/syntax errors.

The current implementation is in [src](../../src). Use the
[README](../../README.md) and [tutorial](../guides/tutorial.md) for its public API.

The original design sketches remain at their existing paths:

- [Initial design and naming](../../final-design.md)
- [Alternative declaration patterns](../../final-design-2.md)
- [Early implementation plan](../../final-design-3+plan.md)
- [v14 findings and plan](../../final-design-4+plan.md)

Later [specifications](../superpowers/specs) and [plans](../superpowers/plans)
record subsequent development. The [documentation map](../README.md) explains
which documents are current guides and which preserve historical evidence.
