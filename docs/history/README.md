of concept. They are excluded from the active build and published package.
Some require obsolete dependencies or contain intentional type/syntax errors.

The current implementation is in `src/` at the repository root. The original
findings remain in `final-design-4+plan.md` at the repository root; the current
spec and implementation plan are under `docs/superpowers/`.
